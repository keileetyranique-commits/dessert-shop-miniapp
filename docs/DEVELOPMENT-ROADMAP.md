# 持续开发路线图

2026-11-03 接管。每轮只完成一个可独立验证模块；每轮更新本表、NAS-PROJECT-HANDOVER 和 PRODUCT-REQUIREMENTS-MAP。历史功能 PR 仍需人工审查，不自动合并。

| 阶段       | 当前真实状态                                                          | 独立验收标准与依赖                                                                                                |
| ---------- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| A 接管     | Git、架构、目录/路由/模型和部署检查完成；接管报告已建，沿用完整状态表 | 证据可复核，真实/Mock/占位区分，禁止覆盖用户成果                                                                  |
| B 基础经营 | 库存 #28 已交付；本轮只补门店资料页面                                 | 老板读取/保存名称地址电话营业说明；其他角色只读；失败保留输入；切店隔离；桌面小屏验收。沿用现有 API，无新依赖迁移 |
| B 后续模块 | 选项组维护、媒体回收、员工权限、POS 提醒、成本历史仍缺                | 各开小 PR；归档历史与在途单安全、媒体引用保护、凭据撤销和审计、接单后停止循环、历史不可覆盖分别验收               |
| C 顾客闭环 | 小程序只有骨架                                                        | 独立顾客认证，不传商家 Token；真实菜单与服务端结算；Mock 真机全流程；履约模块配置                                 |
| D 真实接入 | 支付配送只有适配契约/模拟                                             | 先确认环境密钥费用与沙箱；微信验签/幂等/对账，顺丰/达达报价发单取消回调，实时通知                                 |
| E 成本利润 | 已有确定性算法/API/补录，非从零开始                                   | 补历史界面、成本变化影响和提醒；缺数据不能判断盈利，保持整数计算                                                  |
| F 会员营销 | 未有真实会员/券账本                                                   | 草稿、利润模拟、老板发布、暂停、核销/积分幂等及效果；不伪造稀缺                                                   |
| G 数据中心 | 首页指标占位                                                          | 真实销售退款口径、排除测试单、统计周期与样本；CSV/XLSX/JSON/ZIP 白名单脱敏及字段说明                              |
| H 智能经营 | 设计文档，尚无实现                                                    | 本地统计证据包先行；多 Provider/预算；建议有来源周期样本估算；计划审批暂停重研判版本对比和复盘                    |
| I 平台上线 | 租户隔离已有，自定义字段/开关仅预留                                   | 行业模板与非糖水回归、权限审计、备份恢复演练、监控与迁移手册；不对公网直接开放后台                                |

门店“营业时间说明”本轮是展示资料，不是可执行营业时间规则；门店启停、定位、配送范围和自动接单策略各有后续验证，不暗中扩展本轮范围。
