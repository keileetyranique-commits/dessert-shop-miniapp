## Codex 工作规则

1. 每个 Phase 单独分支。
2. 每个 Phase 先写测试再完成功能。
3. 不允许把 Secret 写进仓库。
4. 所有金额使用整数分。
5. 支付/退款/配送回调必须幂等。
6. 任何 Mock 能力必须可由服务端总开关完全禁用。
7. 每完成一个 Phase，更新文档和迁移脚本。
8. 不允许一次性大改全部模块；使用小 PR。
